# Posto de Gasolina

Free Portuguese (Brazil) static site for drivers: fuel-cost calculator, trip planner, km/L consumption calculator, EV vs petrol cost comparison and ethanol vs petrol comparison, plus a Brazilian fuel reference table and six practical guides about finding cheap fuel, saving fuel and staying safe at petrol stations.

Built with pure HTML, CSS and vanilla JavaScript. No external libraries, no webfonts, no tracking. Deploy the files as-is to GitHub Pages.
